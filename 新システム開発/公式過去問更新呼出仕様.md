# 公式過去問更新 呼出仕様

## システム識別
- systemId: qualification-learning-system
- repository: mda813453dm-arch/qualification-learning-prompt
- branch: ai-learning-system
- main および master_prompt.txt は更新対象外とする。

## チャットからの更新要求
別チャットを含め、ユーザーの発話から本システムを一意に特定でき、かつ公式過去問の更新意思が明確な場合は、公式過去問年度更新要求として扱う。

代表例:
- 「資格学習システムの過去問を更新して」
- 「資格学習システムの公式過去問を更新」
- 「開発中の資格学習システムで年度更新して」
- 本システムについて会話中の「過去問を更新して」

「過去問を更新して」だけで対象システムを一意に特定できない場合は、別システムを推測して変更しない。

## 更新処理の標準範囲
1. 登録済み資格の公式過去問掲載元を確認する。
2. 新年度資料は公式掲載を確認できたものだけ候補にする。
3. 問題と正答を別々に掲載状態・取得状態として扱う。
4. URLを年度規則などから推測生成しない。
5. 最新の公式掲載年度を起点に10年度分を active とする。
6. 10年度を外れた資料は archive とし、通常学習候補から外す。
7. 資格マスタ・閲覧表・更新結果を同期する。
8. 自動テストを実行し、未確認項目をPASS扱いにしない。

## 実行経路
- GitHub Actions: Qualification master sync
- 定期: 毎年4月1日（JST）の年度更新確認
- 任意: workflow_dispatch による手動実行
- チャット環境にGitHub Actions起動機能がある場合は更新要求から直接起動する。
- 起動機能がない環境では、起動したと偽らず、利用可能な実行経路を明示する。

## 安全条件
- 公式掲載確認前に新年度へ強制移行しない。
- 個別PDFの一時的な取得失敗を「掲載なし」に変更しない。
- main/master_prompt.txt を変更しない。
