# 決定論的な資格学習クライアント（検証実装）

## 目的と境界
- **学習操作をAIへ委ねず、JavaScriptの状態機械が進行を確定する**。AIからの自由文に従って問題・正答・図表・次問を変更する機能は持たない。
- ChatGPT/Claude/Perplexity通常チャットにGitHubのJavaScriptを貼っても、そのプログラムが強制実行されるわけではない。したがって**通常チャットにプロンプトを貼るだけで決定論的制御を保証することはできない**。
- この検証実装はスマートフォンブラウザで実際にコードを実行する別の画面である。従来のAIチャットを自動的に置き換えるものではない。AIアプリ内への強制接続は未実装であり、通常AI画面での完全動作は未達。
- `main` と `master_prompt.txt` を変更しない。

## 実装済み
1. `capabilities.json` と `manifest.json` を取得して、verified_official が登録された資格のみ選択可能。
2. `packetUrl` を読み、年度・区分・分野・問題ID・問題文・全選択肢・正答・公式検証証跡を検証。不完全なものは即停止。
3. 公式ページ画像がある場合、登録済みGitHub公式画像の**バイト列のSHA-256** とPNG署名を検証し、画像デコードが完了するまで回答待ちを開かない。外部検索画像や非公式サイトへの置換なし。
4. 画像を含む問題、全選択肢および番号回答ボタンを表示。問題本文が公式ページ画像に入っているpacketでは、説明文を問題本文として出さない。
5. 正答・採点は登録済みデータから決定し、次問・終了を状態機械で制御。未検証の回答/画面/問題IDの流用を拒否。
6. 同一分野で3問連続誤答時に確認問題が未実装なら停止し、AIに代用問題を勝手に作らせない。
7. GitHub Pagesへ配置するワークフローを追加。自動テストまたは公式画像ハッシュ照合失敗時は公開しない。

## 現在の制約
- 資格マスタ103件の全資格が出題可能になったわけではない。公開済みpacketがある土地家屋調査士20問、宅建1問、測量士補2問のみが対象。
- 試験概要の完全表示・免除制度の正式な判定・個別学習計画の編集・確認問題・解説生成・記憶の永続化・学習時間の終了集計・分散復習の自動割込みは**未実装**。画面上でも未実装と表示し、成功扱いしない。
- 通常AIアプリ画面での動作、GitHub Pages URLの稼働状況、iPhoneでの実機確認は、別途確認が必要。
- この実装はコードと公開済みpacketを信頼するモデル。リポジトリ改ざんや元PDFの内容検証までブラウザ単独で保証しない。

## 自動テスト
```sh
cd 新システム開発
node --test web-study/engine.test.mjs
node web-study/verify-live-assets.mjs
```
後者はネットワークを使い、掲載済み公式図表PNGのSHA-256をダウンロード検証する。GitHub Actionsワークフロー：`.github/workflows/deploy-deterministic-study.yml`。Pagesの使用にはリポジトリ設定で**Source: GitHub Actions** が必要になる場合がある。ワークフローの成功を確認するまで公開成功を宣言しない。

## AIの採用方針（後続実装）
AIに許可するのは、採点後にプログラムから渡された確定済み問題ID・採点結果・正答根拠についての**解説文の提案のみ**。出題・問題順・正答・状態遷移の変更権限は渡さない。解説は資料照合やUI上の分離を別途実装するまで未接続。
