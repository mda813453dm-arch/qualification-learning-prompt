# ChatGPTインライン公式図表表示方式｜実機PASS

更新日: 2026-10-12

## 結論
資格学習システムの図表表示は、公式PDFから必要範囲を切り出したPNGを、通常回答内の画像参照として問題文中の本来の位置に配置する方式を標準採用する。

## 実機確認
- 端末: iPhone版ChatGPT
- 2025年度 土地家屋調査士 午前の部 問2: PASS
- 2025年度 土地家屋調査士 午前の部 問6: PASS
- 確認順序: 問番号 → 問題文 → 〔図〕 → 公式図 → 後続本文/選択肢 → 回答要求
- 画像は独立したMatplotlib Chartではなく、通常回答内の指定位置に表示された。

## 標準処理
1. 公式PDFと対象問題を確定する。
2. 問題本文から図・表の挿入位置を保持する。
3. 公式PDFから必要な図表だけを切り出してPNG化する。
4. 問題を ordered contentBlocks として構成する。
5. text block と image block を原文順に並べる。
6. 通常回答で image block をインライン画像参照として出力する。
7. 問題本文・図表・選択肢・回答要求がすべて揃った場合だけ回答待ちへ遷移する。
8. 回答後は確定済み公式正答で採点し、採点時に再検索しない。

## 禁止
- Matplotlib Chartによる問題図表示
- 図を回答先頭や末尾へ分離すること
- 複数図をまとめて別位置へ表示すること
- 公式図をAI生成画像で代替すること
- 表示成功前に出題済み状態へ遷移すること
- HTML外部画面を最終表示方式とすること

## 汎用化条件
特定資格・問番号へのハードコードは禁止。図なし、図1枚、複数図、表、図表混在、ページ跨ぎを同じ contentBlocks モデルで扱う。
