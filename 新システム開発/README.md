# AI対話型学習支援システム｜開発の入口

## 利用画面の確定方針（2026-10-15）
- **正式な利用画面はChatGPT・Claude・Perplexityの通常AIチャット画面**。資格名の入力、概要、計画、出題、採点、復習、次問は同じ会話内で行う。
- AIチャット向け正本の入口は [AIアプリ学習開始プロンプト_開発テスト版.md](AIアプリ学習開始プロンプト_開発テスト版.md)。呼出文面はこのファイルを取得して実行する。web-study/index.html やGitHub Pagesの起動を必須条件にしない。
- web-study は**独立Web画面の技術検証資産**として保管するが、AIチャット版の代替・完成判定・ユーザー向け起動経路には使用しない。
- 通常チャットでGitHubのJavaScript状態機械が自動実行されると主張しない。公式問題・正答・図表を取得・照合・表示できないときは成功と偽らず停止する。
- AIチャット版での出題・採点・次問・復習・図表表示は各AIアプリの実機で別々に確認する。**プロンプトによる遵守は決定論的な強制制御ではない**。完全保証にはAIアプリから呼び出せる実行環境と連携機能が必要であり、未接続は未実装として扱う。
- main と master_prompt.txt は変更しない。


このプロジェクトは現行資格学習マスタープロンプトと別枠です。ChatGPTの会話画面で、学習者がその時に必要な過去問、解説、復習、質問を自然な日本語で依頼できる学習支援システムを目指します。将来のnote紹介・収益化は目標であり、公開・販売は別途承認が必要です。
