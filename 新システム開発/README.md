# AI対話型学習支援システム（新規開発）

## 目的
ChatGPTなどのAI会話画面で、利用者が自然な日本語で学習内容を指定・変更できる柔軟な家庭教師を開発する。過去問演習、詳しい解説、質問、復習、学習相談を一体化する。

## 重要な分離
このブランチ `ai-learning-system` は新規開発専用。既存の `main/master_prompt.txt` と固定版、過去問索引は変更しない。以前の `runtime-engine-candidate` は参考資料として調査する。

## 担当
- ChatGPT：開発主担当、設計・実装・検証・修正・記録
- Claude：必要時の独立レビュー
- Perplexity：必要時の技術調査
- 利用者：重要方針・公開の承認

## 設計原則
1. AIが利用者の学習意図を理解し、会話を主導する。
2. 公式問題・正答の照合と採点は根拠が確認できる場合に限る。
3. 学習中の自由な話題変更を許容する。特定資格に固定しない。
4. ChatGPTの通常画面から外部制御を利用できるか先に実証する。保証できないことを保証しない。
5. スマホでの利用を優先する。
6. 将来のnote紹介・収益化を想定するが公開・販売は別途承認する。
