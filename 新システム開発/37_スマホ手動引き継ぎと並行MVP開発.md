# スマホ用・追加料金なしの学習引き継ぎ仕様（2026-10-11）

## 方針
ChatGPT iPhoneアプリでカスタムMCP接続が未実証のため、フェーズ2は「外部接続未実証」と記録し、**フェーズ3の対話型MVPを並行して進める**。フェーズ2が未完了でも、会話画面内で実証可能な機能の開発を止めない。追加の有料サービスは使わない。

## 利用者の操作（スマホ）
1. 現在のチャットで「学習引き継ぎを出力して」と入力する。
2. AIは下記の**人が読める日本語形式**で資格・現在の学習モード・弱点・再開時の希望を表示する。利用者が未申告の項目は「未確認」とする。
3. 利用者がそのブロックをコピーし、次のチャットへ貼り付け「この内容を引き継いで続けて」と入力する。
4. AIは引き継ぎ情報を利用者申告として扱い、未検証の公式問題・正答・免除制度を確定済みにしない。

## 出力形式（例示。事実を推測で補完しない）
```text
【資格学習 引き継ぎ v1】
資格：土地家屋調査士
学習モード：復習
弱点分野：未確認
直前の問題：未確定（必要なら再取得）
再開時の希望：前回の学習を続ける
【注意】これは利用者申告の学習メモです。公式問題・正答の検証結果は引き継ぎません。
```

## 制約
- Node.js用の `portable-handoff.js` はこのチャット内で自動実行されるものではない。スマホ向けには上記の読みやすい手動方式を優先。
- AIが自動的に他チャットの全履歴・添付PDFを復元できるとは限らない。必要なPDFは再添付してもらう。
- 個人情報、認証トークン、回答前の正答を引き継ぎ文に含めない。
- 学習状態の自動永続保存は未実装。公式問題の完全照合ができない場合は採点しない。

## 進捗の扱い
フェーズ2：未完了（スマホ外部接続は未実証）。フェーズ3：並行進行中。現行マスタープロンプト・mainは変更しない。
