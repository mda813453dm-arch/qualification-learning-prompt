# ChatGPT会話内・資格学習実行契約（開発版）

## 目的
ユーザーがZIPやHTMLを開かずにChatGPTアプリの通常の会話で「出題→番号回答→採点→解説→次問」を実行する。GitHub Actionsの成功はiPhoneでの動作成功を意味しない。

## 前提条件
1. 公式問題PDFと同年度・同区分の公式正答PDFを取得し、問番号・本文・全選択肢・図表・正答セルを照合する。
2. 取得済みの確定packetを回答待ち前に保存し、採点時に再検索しない。
3. 問題本文・選択肢・公式図表が欠ける場合は問題を出さず停止し、欠けた資料と再取得手段を示す。
4. 図表は公式PDFから実際に抽出した画像ファイルを参照する。ダミーのsandboxパス、URLへの任意のクエリ追加、文字の代用、描き直しは禁止。
5. 画像の本文インライン表示は、実ファイルの存在とその会話の表示を確認してから成功判定する。添付ファイルリンクだけでは成功としない。

## 会話状態遷移
- INIT → SOURCE_VERIFIED → QUESTION_PACKET_READY → AWAIT_ANSWER
- AWAIT_ANSWER → GRADED（回答が1〜4で、packetに正答照合済みのときのみ）
- GRADED → EXPLANATION → NEXT_PACKET_READY → AWAIT_ANSWER
- 取得失敗 → BLOCKED（理由と手動PDF添付方法を提示）
- すべての表示を1回答内で完了できない場合は未出題扱いとする。

## ユーザー画面
- ■2025年度 問29
- 公式問題本文、必要な公式図表、選択肢1〜4
- 「番号で答えてください。」
- 回答後：正誤・正答番号・公式正答PDFリンクとページ・各選択肢の解説
- 解説後は同じ応答で次問を完全表示。完了不能なら再取得の具体的な選択肢を提示。
- 開発ログ、ハッシュ、ツール状況は通常の学習画面に混ぜない。

## 禁止事項
- 未照合のANSWERS配列や暫定HTMLの答えを正式採点に使わない。
- GitHubのPython/JSプログラムがChatGPT会話内で自動実行されると偽らない。
- 実行経路がない状態で「システムが完成」と宣言しない。
- 1問先のpacket未取得で「次問を出します」とだけ書いて終了しない。

## 実装上の残課題
- GitHubの問題抽出とChatGPT会話との確実な接続
- 公式正答PDFの問番号別セル照合
- 図表の抽出とiPhoneの通常回答内インライン表示
- 次問packetの事前取得と採点後の連続出題
- 公式PDFを用いた実機総合試験
