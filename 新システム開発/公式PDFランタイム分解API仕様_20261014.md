# 公式PDFランタイム分解API仕様

最終更新: 2026-10-14

## 1. 目的
資格学習時に、全資格・全年度の過去問本文を事前保存せず、必要になった公式PDFをその都度システムへ渡し、問題単位へ分解・検証してAIへ返す。

## 2. 全体フロー
1. AI/AI連携層が資格マスタ・年度別候補台帳から公式問題PDFと同年度公式正答PDFを選ぶ。
2. AI/AI連携層がPDF本体を取得する。
3. 取得したPDF本体、qualificationId、requestedFieldId、year、section、元URL、既知SHA-256をランタイムへ渡す。
4. ランタイムがPDF形式、既知SHA-256、問題本文、全選択肢、図表、問番号、正答表を解析する。
5. 各問題をfieldIdへ分類する。
6. requestedFieldIdと一致し、本文・選択肢・必要図表・同年度正答がすべて揃った問題だけをruntime_official_pdfパケットとして返す。
7. AIは返却パケットのstem/choicesをそのまま表示し、correctAnswerを隠して回答を待つ。
8. 回答後は回答待ち前に保持した同一questionIdのcorrectAnswerで採点する。

## 3. 入力
ランタイムは最低限、次を受け取る。
- qualificationId
- requestedFieldId
- year
- section
- questionPdfs[]: PDF本体、元URL、既知SHA-256（ある場合）
- answerPdf: PDF本体、元URL、既知SHA-256（ある場合）
- setSize

PDF本体を取得していないURLだけの入力は、問題本文の分解成功として扱わない。

## 4. 出力
成功時:
- status=ready
- sourceMode=runtime_official_pdf
- packets[]

各packet:
- qualificationId
- fieldId
- unitId（判定できる場合）
- year
- section
- questionId
- questionNumber
- stem
- choices
- correctAnswer
- diagramRequired
- diagramAssets
- questionPdfUrl
- answerPdfUrl
- questionPdfSha256
- answerPdfSha256
- verification

verification:
- questionText=runtime_pdf_checked
- choices=runtime_pdf_checked
- answer=same_year_official_answer_checked

## 5. 不合格条件
次のいずれかがあれば出題可能パケットにしない。
- PDF本体が有効なPDFでない
- pinがあるのにSHA-256不一致
- 問題本文が空
- 選択肢が不足または欠落
- 正答が選択肢範囲外
- 同年度・同区分の公式正答と対応できない
- requestedFieldIdと一致しない
- 必須図表があるのに図表資産を返せない
- 問番号/問題IDの一意性が担保できない

## 6. 保存方針
公式PDFが正本。全資格・全年度の問題本文を恒久的な問題DBとして事前構築しない。

ランタイムの処理中はPDF本体と分解済みパケットを一時保持してよい。キャッシュを実装する場合はPDF SHA-256とparserVersionをキーとする短期キャッシュとし、キャッシュが無くても同じPDFから再生成できることを前提とする。長期保存が必要になった場合は別仕様として利用目的・保持期間・更新方法を明示する。

## 7. 公式PDF候補台帳
年度別候補台帳は過去問本文を保存するものではなく、公式PDFを見つけるためのURL・年度・区分等のメタデータである。測量士補の候補台帳:
- 新システム開発/data/official-pdf-candidates/assistant-surveyor.json

ランタイム中核:

## 9. AIアプリとの接続
GitHub上にJavaScriptが存在するだけでは、通常のChatGPT/Claude/Perplexity画面から自動実行できない。実機でこのフローを成立させるには、AIアプリからPDF本体を渡し、JSONパケットを受け取れるAPI/コネクタ/ツール接続が必要。

未接続時に「システムがPDFを分解した」と表示してはならない。

## 10. 受入テスト
- PDF本体→問題3問→同年度正答対応→同一fieldId3問→runtime_official_pdf返却
- 1問の選択肢欠落→その問だけ除外
- 正答PDFが別年度→全件拒否
- SHA-256不一致→該当PDF拒否
- 図表必須かつ資産なし→該当問拒否
- setSize未満→SAME_FIELD_COMPLETE_PACKETS_INSUFFICIENT
- ランタイム未接続→成功を偽装せず、実装未接続として停止
