# AI裁量排除｜決定論ステートマシン仕様
更新日: 2026-10-12

## 最優先原則
AIは自然言語の意図理解と説明文生成だけを担当する。出題対象、資料選択、問題境界、図表位置、完全性判定、正答、採点、状態遷移、次問選択をAIの自由判断に任せない。

## 単一状態機械
IDLE → QUALIFICATION_FIXED → SOURCE_FIXED → QUESTION_FIXED → ASSETS_FIXED → PACKET_VALIDATED → RENDERED → ANSWER_WAIT → GRADED → EXPLAINED → NEXT_FIXED

各状態には機械判定可能な入口条件・出口条件を持たせる。条件未達なら次状態へ進めない。

## QuestionPacket 必須項目
- qualification_id
- year
- session/section
- question_no
- source_problem_url/file_hash
- source_answer_url/file_hash
- exact_text_blocks[]
- content_blocks[] (text/image/table)
- assets[] (source page, crop coordinates, hash)
- choices[]
- official_answer
- answer_evidence
- packet_hash

いずれか欠落なら INVALID とし出題禁止。

## content_blocks
原文順を固定し、type=text/image/table の配列として保持する。rendererは配列順以外の並べ替えを禁止する。imageは公式PDF由来の確定済みPNGのみ許可する。

## 図表表示
2026-10-12 iPhone実機PASS方式を唯一の標準経路とする。
公式PDF→確定crop→PNG→通常回答内画像参照。
Matplotlib、AI再描画、文字図への自動代替、外部HTMLへの自動切替は禁止。

## 採点
official_answer は QuestionPacket 確定時に固定する。回答後の再検索禁止。packet_hash が変化した場合は採点禁止。

## 状態遷移ガード
- RENDERED: 全 content_blocks と全 choices と回答要求の出力成功が必要
- ANSWER_WAIT: RENDERED=true のときだけ
- GRADED: ユーザー入力が有効選択肢かつ pinned answer 存在時だけ
- NEXT_FIXED: 解説完了後にプログラムが次行動を決定
AIが状態値を書き換えることは禁止。

## fail-closed
取得・抽出・crop・画像参照・正答照合・完全性検証のどれかが失敗したら出題しない。AIによる補完・推測・類題生成への無断切替は禁止。規定の再試行処理だけ実行し、上限到達後に機械的な失敗メニューを返す。

## 二重照合
問題本文、選択肢、図表、正答について、source locator と hash/evidence を保持する。表示直前に packet validator、採点直前に answer binding validator を通す。

## 冪等性
同じ packet_id + state + user_input なら同じ処理結果にする。再送で別問題・別正答・別図へ変化させない。

## AIに許可する処理
- 普通の日本語からユーザー意図を分類
- 確定済みデータを用いた解説
- 学習上の補助説明
ただしプログラム確定値を変更しない。

## AIに禁止する処理
- 問題/年度/図/正答を推測
- 不足データを創作
- 公式図を独自再描画
- 表示順変更
- 採点時再検索
- validator bypass
- 「たぶん成功」として次状態へ進行
- 失敗時に規定外の方法へ勝手に切替

## 合格条件
単体テストだけでは完成扱いにしない。ChatGPT実画面で、図なし・図1枚・複数図・表・図表混在・ページ跨ぎ・取得失敗・再試行・採点・解説後次問までE2E PASSして初めて当該フェーズを合格とする。
