## 1. 全体の流れ

```
[資格名の入力]
   │ ① 学習エンジンが「取り込みジョブ」を登録（導入6段階の会話は並行して進む）
   ▼
[取り込みジョブ]（資格の全年度・全PDFについて）
   公式PDF取得 → SHA-256計算 → 24時間保存を確認
     ├ 保存あり（24時間以内）→ そのまま使う
     └ 保存なし／期限切れ → 分解（経路A：サーバーなし → 失敗時 経路B：Cloud Run）
                              → 検査（F1の中核）→ 24時間保存へ書き込み
   ▼
[出題]  学習エンジンが分野・復習条件から問題を選び、AIへパケットを返す
   ▼
[AIの会話画面]  本文・選択肢・図をそのまま表示 → 回答 → 学習エンジンで採点 → 次問／復習
```

## 2. 共通の分解プログラム（1つだけ）

- **言語は Python、PDF処理は PyMuPDF とする（提案）。** 理由：ChatGPTやClaudeのコード実行は Python が標準で、Cloud Run でも同じコードがそのまま動く。図の切り出しも既存資産が Python。JavaScript の分解コード（F2）は新方式では使わず凍結する。
- PyMuPDF が使えない環境に備え、文字抽出だけは pypdf でも動く作りにする（図が必要な問題はその場合「出題不可」にする）。
- 構成：
  - `qlp_parser/core.py`：PDF検査、SHA-256、ページ文字抽出、図の切り出し、パケット組み立て、不合格判定（F1の検査規則をそのまま移植）
  - `qlp_parser/adapters/<資格>.py`：資格ごとの「問番号の見つけ方」「選択肢の形」「正答表の読み方」だけを書く。最初は **宅建**（文字のみ・4択・正答表が問題PDFの最終ページ）と **測量士補**（図表あり・5択・正答が別PDF）の2つ
  - `qlp_parser/cli.py`：経路A・Bの共通の入口
- **入力**：資格ID、年度、区分、問題PDF（本体・元URL・既知SHA-256）、正答PDF（同）、parserVersion
- **出力**：`status`（ready／partial／unavailable）、理由コード、問題ごとのパケット（既存仕様 `公式PDFランタイム分解API仕様_20261014.md` §4 と同じ項目＋`figures[]`：図のPNGとその位置）、除外した問題と理由の一覧
- **1つのPDFを最後まで分解し、問題ごとに合否を付ける。** 1問の失敗で全体を止めず、その問だけ出題不可にする。

## 3. 経路A（サーバーなし）と経路B（Cloud Run）の切替条件

- 経路A：AIアプリのコード実行で `cli.py` を動かす。経路B：Cloud Run で同じ `cli.py` を動かす（F4のサーバーを土台に、入口を差し替える）。
- **経路Bへ切り替えるとき**（どれか1つ）：
  1. 経路Aの環境に PDF 本体が届かない（コード実行がネットに出られず、添付もない）
  2. PyMuPDF が使えず、その問題に図が必要
  3. 経路Aが異常終了、または時間切れ
  4. 経路Aの出力が検査で不合格（問数不足、正答対応なし等）
- 同じPDF・同じ parserVersion なら、どちらの経路でも同じ出力になることを受入テストで確認する（バイト単位で比較）。
- **重要な懸念（推測、T2で要確認）**：ChatGPTのコード実行は外部サイトにアクセスできない可能性が高い。そうだと、経路Aは「水野さん（利用者）がPDFを添付したとき」しか使えず、資格名入力時の自動取り込み（方針3）は実質、経路Bが主役になる。T2の結果でこの前提を確定させる。

## 4. 24時間保存

- 保存先：Cloudflare R2（PDF本体・図のPNG・パケットJSON）＋ KV（目次。取得時刻・期限・状態）。
- キー：`<資格ID>/<年度>/<区分>/<PDFのSHA-256>/<parserVersion>/...`
- **期限の判定はプログラム側**で行う（取得時刻＋24時間を過ぎたら「なし」として扱い、再取得）。R2 の自動削除設定は日単位なので、掃除用の補助としてだけ使う。
- 取り込みに時間がかかるとき：取り込み状態（待ち／処理中／完了／失敗）をKVに持ち、学習エンジンがAIへ「過去問の取り込みに時間がかかっています」と返す。
- 未決定事項「資格単位で24時間共有するか」は、キーに利用者IDを入れない設計にしておけば後から選べる（共有しない場合は利用者IDをキーに足すだけ）。

## 5. 引継ぎ形式（問題本文を含めない）

```json
{
  "schema": "qlp-handoff-v1",
  "qualificationId": "takken",
  "questions": [
    {"year": 2025, "section": "年度共通", "number": 29,
     "questionPdfUrl": "https://...", "questionPdfSha256": "829c...",
     "answerPdfUrl": "https://...", "answerPdfSha256": "829c...",
     "result": "wrong", "answeredAt": "2026-10-15", "reviewDue": "2026-10-18"}
  ],
  "plan": {"fieldWeights": {"takken-u7": 3}, "examDate": "2026-10-18"}
}
```
- 再開時は SHA-256 を照合し、公式PDFが差し替え・削除されていたら、その問題は出題せず理由を表示する（方針5）。
