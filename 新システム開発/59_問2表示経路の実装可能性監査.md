# 59｜問2表示経路の実装可能性監査（2026-10-12）
## 結論
現状のChatGPT iPhoneアプリの通常会話では、GitHubのJavaScriptから「通常テキスト→公式図画像→通常テキスト」の描画順序を強制する実行APIを確認できていない。**未完成／実機未合格**。
## 実測
- Python可視ツールで画像を返す方式は、ツール結果が別表示ブロックとなり、直前の通常テキストがiPhoneで見えない事象を繰り返し確認した。
- ordered-content-question.js、render-contract.js、q2-render-fixture.jsは表示内容・順序を検査するコードであり、ChatGPTアプリの表示エンジンを制御しない。
- 「commitAll」等の受領値は自前の宣言に過ぎず、ユーザー画面の実表示を証明しない。
## 公式仕様確認
- https://help.openai.com/en/articles/12584461-developer-mode-and-mcp-apps-in-chatgpt : custom MCP apps は web only と明記。iPhone通常チャットの描画経路の代替にはならない。
- https://developers.openai.com/plugins/concepts/ui-guidelines : inline app UI はモデル応答の前に表示される。任意位置に差し込める保証はない。
## 安全停止条件
- 実表示が確認できるまでは「問2合格」「表示完成」と報告しない。
- AIが通常テキストと画像ツール結果を別々に送る既知不合格方式で再試験しない。
- 図を再描画したり、全ページ画像に置換して合格扱いにしない。
## 未解決の実装条件
1. ChatGPT iPhone通常会話内で、文字列と公式図画像を同一の回答として順序どおり表示する**実際の出力経路**を確認する。
2. その経路を使う実装を作る（単なる型定義・検査コードでは不可）。
3. 問2をiPhoneで実測し、問番号／全文／図／ア～オ／選択肢／回答要求の全要素を確認する。
4. 正答は回答前に非表示、回答後は固定済み公式正答で採点。
## 判断
現時点で 1 を満たす利用可能なインターフェースが確認できない。外部Webアプリに切り替えることはユーザーの「ChatGPTスマホ画面で」という要件を変えるため無断変更しない。
