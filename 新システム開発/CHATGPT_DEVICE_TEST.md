# iPhone ChatGPT 実機テスト入口（開発版）
対象: ai-learning-system。main/master_prompt.txt は変更しない。

## テスト範囲
ChatGPTの通常会話内で公式PDFをその都度取得し、問題本文・全選択肢・公式正答・図表を照合して1問を完全表示する。回答番号を受けて固定済みpacketで採点し、次問は同一項目の未出題公式問題を年度横断で選ぶ。期限復習があれば優先する。

## 実行条件と禁止
GitHubのJSがChatGPTアプリ内で自動実行されるわけではない。ChatGPTがGitHubソースを読んだだけで実装済みプログラムが実行されたと主張しない。実際にJSを実行できない環境では「橋渡し未接続」と報告し、AIの推測をシステム実行と混同しない。
PDF本文・選択肢・正答セル・必要図表の照合ができなければ出題禁止。図表の代用・未確認画像パス・答えの推測は禁止。
ChatGPT通常画面での実機PASSは、公式PDFから実際に出題→番号回答→正答根拠付き採点→同一項目の別年度問題の完全表示まで確認して初めて宣言する。

## PASS基準
1. 実機で公式の問題・全択・必要図が正しい位置に表示される。
2. 正答PDFの同年度・同区分・同問セルと照合して採点する。
3. 同一項目の未出題問題を、必要に応じて異なる年度から選ぶ。
4. 復習の期限・誤答・確認問題の処理がD07/B15/B16の規定に沿う。
5. 回答後に説明だけで止まらず、次の完全問題または正規復旧画面に到達する。
6. 会話間の保存・復元は保存先が実際に接続されている場合に限りPASS。
