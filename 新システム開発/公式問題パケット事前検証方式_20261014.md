# 公式問題パケット事前検証方式

最終更新: 2026-10-14

## 1. 目的
AIアプリが学習時に公式PDFを直接取得・抽出できるかどうかに、公式過去問学習の成否を依存させない。

## 2. 基本構成
公式PDFは登録・更新時の正本資料とする。学習時は、公式PDFから事前に検証した構造化問題パケットを第1経路として使用する。

実行順:
1. verified-question-packets/index.json を取得
2. qualificationId と fieldId/fieldAliases を解決
3. 対応するパケットJSONを取得
4. schema/資格/分野/問題ID/本文/選択肢/正答/検証状態を検査
5. 必要セット数が揃えばパケットから直接出題
6. 不足・検証失敗の場合だけライブ公式PDF取得へフォールバック

## 3. verified_official の成立条件
各問題について次をすべて満たす。
- 公式問題PDFで問題番号・本文・全選択肢を確認済み
- 必要な図表がある場合は表示可能な検証済み資産を登録済み
- 同一年度・同一区分の公式正答表で正答番号を確認済み
- qualificationId / fieldId / questionId / year / questionNumber が確定
- correctAnswer が選択肢範囲内
- questionId が一意

満たさない候補を verified_official に昇格させない。

## 4. 学習時の規則
verified_official が必要数ある場合、元PDFを学習時に再取得しない。問題本文・選択肢はパケット値をそのまま表示する。採点は回答待ち前に保持した同一questionIdのcorrectAnswerを使う。採点時に別年度・別問題を検索し直さない。

公式問題PDFと公式正答PDFのURLはパケットのprovenanceとして保持し、出題時は正答を見せず、採点後に正答番号と公式資料URLを表示する。

## 5. ライブPDF取得の位置付け
ライブPDF取得は、事前検証パケットが不足する資格・分野のフォールバックである。有効な事前検証パケットが必要数あるのにライブPDFの取得失敗を理由として出題停止してはならない。

## 6. 測量士補の初期実装
qualificationId: q063
fieldId: q063.surveying_law
fieldAliases: 測量に関する法規 / 法規

正本:
- index: 新システム開発/data/verified-question-packets/index.json
- packet: 新システム開発/data/verified-question-packets/q063/surveying-law-r4.json
- runtime: 新システム開発/src/verified-question-packet-store.js

令和4年の公式問題3問をverified_officialとして登録する。問題元は国土地理院公式問題PDF、正答元は同年度の国土地理院公式解答PDF。

## 7. 受入条件
q063.surveying_lawで3問セットを要求した場合:
- index取得成功
- packet取得成功
- 3問すべてvalidation ready
- sourceMode=preverified_official_packet
- 第1問の本文+全5選択肢+「番号で答えてください。」を表示
- PDF添付要求を出さない
- 「公式問題を取得できませんでした」を出さない
- AI作成問題へ自動切替しない
- 回答後は同一questionIdの保存済み公式正答で採点

## 8. 拡張
他資格・他分野も同じスキーマで追加する。新年度は候補PDFを登録しただけでは学習時利用可とせず、検証完了後にパケット化してindexへ追加する。
