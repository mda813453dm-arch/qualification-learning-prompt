# 共通の分解プログラム（qlp_parser）

公式の問題PDF・正答PDFを、その場で問題単位に分解して出題用パケットにする。
経路A（AIアプリのコード実行）と経路B（Cloud Run）で同じコードを動かす。設計は T1 設計計画（Notion「資格学習システム｜開発状況・引継ぎ【現行】」から参照）。

- 必要なもの：Python 3.10以上、PyMuPDF 1.26.5
- 実行例：`python -m qlp_parser.cli --adapter takken --year 2025 --question-pdf R7.pdf --question-url <公式URL>`
- テスト：`python -m unittest discover -s tests`（実PDFの受入テストは `TAKKEN_R7_PDF=<パス>` を付けたときだけ動く）

## 現状（v0.1.0）
- 宅建アダプタ：見出し【問 n】・4択・正答表（問 a … 問 b の行）。図・表がありそうな問題は、図を返せるまで出題しない。
- 宅建R7公式PDF（SHA-256 829cde57…）で受入テスト合格：50問すべて出題可能、正答50問が既存索引と一致、問29が検証済みパケットと一致。
  全50問の本文・選択肢を元PDFの文字と照合し、差はふりがな（瑕疵の「かし」、防錆の「せい」）と注意書きのみ。
- 対策済みの誤結合：ふりがな行の混入、版面のトンボ・枠を図と誤認、裏表紙・正答表ページの混入、最終選択肢への注意書きの混入、本文中の「1 年…」行や折り返し行「2 年…」を選択肢と誤認。
- 分野判定は未実装（fieldId は null、verification.field は unverified）。
- 測量士補アダプタ（図表あり）は次の工程。
