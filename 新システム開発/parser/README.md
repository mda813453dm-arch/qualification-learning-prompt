# 共通の分解プログラム（qlp_parser）

公式の問題PDF・正答PDFを、その場で問題単位に分解して出題用パケットにする。
経路A（AIアプリのコード実行）と経路B（Cloud Run）で同じコードを動かす。設計は T1 設計計画（Notion「資格学習システム｜開発状況・引継ぎ【現行】」から参照）。

- 必要なもの：Python 3.10以上、PyMuPDF 1.26.5。日本語が図形になったPDF（測量士補R8など）を文字にするには Tesseract と日本語データ（Ubuntu: `apt-get install tesseract-ocr tesseract-ocr-jpn`、開発時は 5.3.4）。
  Tesseractが無い環境（経路Aのアプリ側で入っていない場合など）では、本文を公式PDFの画像で見せる形に自動で切り替わる。経路B（Cloud Run）のイメージには入れる。
- 実行例：`python -m qlp_parser.cli --adapter takken --year 2025 --question-pdf R7.pdf --question-url <公式URL>`
- 図の書き出し：`--assets-dir <フォルダ>` を付けると、公式PDFから切り出したPNGを書き出す（パケットの figures にファイル名・SHA-256・切り出し範囲）
- テスト：`python -m unittest discover -s tests`（実PDFの受入テストは `TAKKEN_R7_PDF=<パス>`、`SURVEYOR_R8_Q=<問題PDF> SURVEYOR_R8_A=<正答PDF>` を付けたときだけ動く）

## 現状（v0.3.0）
- 宅建アダプタ：見出し【問 n】・4択・正答表（問 a … 問 b の行）。図・表がありそうな問題は、図を返せるまで出題しない。
- 宅建R7公式PDF（SHA-256 829cde57…）で受入テスト合格：50問すべて出題可能、正答50問が既存索引と一致、問29が検証済みパケットと一致。
  全50問の本文・選択肢を元PDFの文字と照合し、差はふりがな（瑕疵の「かし」、防錆の「せい」）と注意書きのみ。
- 対策済みの誤結合：ふりがな行の混入、版面のトンボ・枠を図と誤認、裏表紙・正答表ページの混入、最終選択肢への注意書きの混入、本文中の「1 年…」行や折り返し行「2 年…」を選択肢と誤認。
- 分野判定は未実装（fieldId は null、verification.field は unverified）。
- 測量士補アダプタ（`--adapter surveyor`、q063・5択・正答は別PDFの「No.n m」）：
  - R8公式PDF（問題 SHA-256 3b797566…、正答 b513b257…）で受入テスト合格：28問すべて出題可能、正答28問が保存済みの正答文字と一致、検証済みの問7・問27とページ・選択肢・正答が一致。
  - R8の問題PDFは日本語の文字が図形（アウトライン）で、文字として取り出せるのは数字・英字だけ。そのため日本語はOCRで文字にする（2026-10-15 水野さん決定：読み間違いは許容。出題時に公式PDFのリンクを表示する）。
    - 1行ごとに図形の文字だけを白紙に描き直してTesseract（psm 7）で読み、数字・英字はPDFの文字をそのまま使う。
    - 読んだ字数が描いた字数と同じ行は1字ずつ対応づけ、同じ形の字は文書全体で多数決をとって読み違いをならす。字数が合わない行は多数決の結果と1字ずつの読み直しで補う。それでも読めない字は「〓」にして notes に `ocr_unknown:n` を残す。
    - 結果は `stemMode` / `choiceMode` が `ocr`、`verification.questionText` / `choices` が `ocr_unverified`。数字・英字だけの選択肢は `text`。
    - 図・表は、その部分（図の上のラベル行〜選択肢の手前）だけを公式PDFから切り出す。図・表の無い問は画像を付けない。
    - 列見出し（ア・イ…）付きの選択肢は「ア：…、イ：…」の形にする。下線部は［ ］で囲む（notes に `underline`）。句点と同じ形の度記号は位置で「°」にする。
    - R8で28問すべて出題可能、読めなかった字は0。残る読み違いの例：楕円体→椿円体、永久→水久、∠ABC→ンABC、ΔX→4X、π→率。読み取り結果の一覧はプロジェクト共有フォルダ「資格学習システム/測量士補R8_OCR読み取り結果.md」。
  - 問番号は見出し「〔No. n〕」の数字の形を並び順と突き合わせて確かめる。形と数字が1対1にならない（ページの抜け・入れ替わり）と全体を出さない。20問未満のPDFでは確かめきれないので出さない。
  - 切り出しは描画倍率3倍（80番の実機確認と同じ）。真っ白な画像は図として返さない。Tesseractが無い環境では1問分（見出し〜最後の選択肢）を切り出し、本文は画像で見せる（`official_image`）。
  - 正答PDFの「令和n年」が指定年度と違えば ANSWER_YEAR_MISMATCH。上付きの単位（m²）は ² にする。
